## 💻 Sobre o Projeto

O projeto foi feito em HTML puro sem nada de CSS ou Java Script, seu objetivo era pra ser uma atividade da faculdade sobre HTML, aprendi muito de como funciona o HTML e como usar ele, além de que como funciona um site por baixo do CSS.

## 🛠️ Tecnologias Utilizadas

- [HTML5]
- [VScode]

## ✨ Funcionalidades

- Mostra o top 10 numeros de 1 a 10]
- Tem coisas basicas do HTML.

## 🚀 Como Executar o Projeto

Instruções passo a passo de como rodar o projeto na sua máquina:

### Pré-requisitos
Antes de começar, você vai precisar ter instalado em sua máquina:
- [Git]
- Um navegador web moderno (Chrome, Firefox, Edge) ou um editor de código como o [VS Code].

### Rodando o projeto
1. Clone este repositório
2. E roda ele ai por meio de algo similar ou o proprio live server(extensão do VScode).
